# Question

[number-of-1-bits](https://leetcode.cn/problems/number-of-1-bits/)



# Answer

> solution

**思路核心：用纯位运算代替循环分支，彻底消除问题。**

1.  **数据结构**：`int` 参数必须视为 `uint32_t` 位模式处理，否则平台依赖性是致命错误。
2.  **消除循环**：不使用 `for`/`while`，而是通过分治加法在常数时间（4步）内完成计算。
3.  **消除分支**：所有操作均为算术和位运算，无 `if/else`，性能稳定。
4.  **输出模式**：最后一步用乘加优化提取总和，保持代码高内聚、低复杂度。

### Way Of C

> source code

```c
int hammingWeight(int n) {
    uint32_t x = (uint32_t)n; // 明确处理为无符号位模式
    
    x = (x & 0x55555555) + ((x >> 1) & 0x55555555);
    x = (x & 0x33333333) + ((x >> 2) & 0x33333333);
    x = (x & 0x0F0F0F0F) + ((x >> 4) & 0x0F0F0F0F);
    
    return (x * 0x01010101) >> 24;
}
```

### Way Of C++

> source code

```c++
class Solution {
public:
    int hammingWeight(int n) {
        // 将 int 参数视为一个 32 位无符号整数的位模式。
        // 这是处理汉明重量的正确方式，因为它关心的是位的设置情况，而不是数值的符号。
        uint32_t x = static_cast<uint32_t>(n);
        
        // 步骤1：对相邻位进行分组与加法。
        // 使用十六进制常量使位操作更清晰。
        x = (x & 0x55555555) + ((x >> 1) & 0x55555555);
        
        // 步骤2：对4位分组进行加法。
        x = (x & 0x33333333) + ((x >> 2) & 0x33333333);
        
        // 步骤3：对8位分组进行加法。
        x = (x & 0x0F0F0F0F) + ((x >> 4) & 0x0F0F0F0F);
        
        // 步骤4：累加所有字节的值。
        // 乘以 0x01010101 将每个字节的值复制并左移，通过一次右移24位提取结果。
        return (x * 0x01010101) >> 24;
    }
};
```
