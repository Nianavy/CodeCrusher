# Question

[3sum](https://leetcode.cn/problems/3sum/)



# Answer

> solution

**算法思路解析**：

1. **排序预处理**  
   `sort(nums.begin(), nums.end())`  
   排序后，数组具有单调性，使得双指针法能有效工作，并且去重逻辑更简单。

2. **固定第一个数**  
   通过 `for` 循环枚举 `i`，每次固定一个数 `nums[i]`，然后在剩余部分寻找两个数 `nums[j]` 和 `nums[k]`，使得三数之和为 0。

3. **去重核心逻辑**  
   - 外层：`if (i > 0 && nums[i] == nums[i - 1]) continue;`  
     防止固定同一个值作为第一个数产生重复三元组。  
   - 内层：在找到解后，通过两个 `while` 循环跳过重复的 `nums[j]` 和 `nums[k]`，确保每个组合只出现一次。

4. **双指针移动**  
   - `sum < 0`：说明当前两个数太小，需要增大，所以 `j++`。  
   - `sum > 0`：说明当前两个数太大，需要减小，所以 `k--`。  
   - `sum == 0`：记录解，并移动指针到下一个不同值的位置。

5. **边界与效率**  
   - 循环条件 `i < n - 2` 保证了 `j` 和 `k` 至少有一个有效区间。  
   - 时间复杂度：O(n²)，来自排序 O(n log n) + 双指针的 O(n²)。  
   - 空间复杂度：O(1)（不考虑结果存储，结果空间取决于解的数量）。

### Way

> source code

```c++
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;  // 存储结果三元组
        sort(nums.begin(), nums.end());  // 排序：为双指针法做准备
        int n = nums.size();
        
        // 外层循环：固定第一个数 nums[i]
        for (int i = 0; i < n - 2; ++i) {
            // 去重：如果当前数与前一个数相同，跳过，避免重复三元组
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            // 内层双指针：在子数组 [i+1, n-1] 上寻找两数之和为 -nums[i]
            int j = i + 1, k = n - 1;
            while (j < k) {
                int sum = nums[i] + nums[j] + nums[k];
                if (sum < 0) {
                    ++j;  // 和太小，需要更大的数，右指针右移
                } else if (sum > 0) {
                    --k;  // 和太大，需要更小的数，左指针左移
                } else {
                    // 找到一组解：{nums[i], nums[j], nums[k]}
                    res.push_back({nums[i], nums[j], nums[k]});
                    
                    // 去重：跳过所有与当前 nums[j] 相同的元素
                    while (j < k && nums[j] == nums[j + 1]) ++j;
                    // 去重：跳过所有与当前 nums[k] 相同的元素
                    while (j < k && nums[k] == nums[k - 1]) --k;
                    
                    // 移动到下一组可能的解
                    ++j;
                    --k;
                }
            }
        }
        return res;
    }
};
```
